# aeo-trust-blocks — AEO: как попасть в ответы ChatGPT и Perplexity

Скилл для аудита и переработки текста под AI-выдачу. Проверяет, насколько
безопасно AI-поисковикам (ChatGPT, Perplexity, Google AI Overviews, Яндекс
Нейро) цитировать ваш контент, и переписывает слабые места в самодостаточные
блоки доверия — **Extractable Trust Blocks**.

## Зачем это нужно

AI-поисковики не читают страницу целиком — они парсят её на фрагменты,
ранжируют по извлекаемости и собирают ответ из лучших. Цитируется не самый
качественный контент, а наиболее **легко извлекаемый и верифицируемый**:

- 69% поисков заканчиваются без клика (2025) — читатель видит ваш текст
  только внутри AI-ответа, если текст туда попал;
- структурированные блоки цитируются в 2,8 раза чаще;
- только 12% AI-цитируемых URL совпадают с топ-10 Google — это отдельная
  игра со своими правилами.

Абзац, который теряет смысл вне контекста («как мы говорили выше», «данный
подход», «стоимость невелика»), AI помечает как рискованный и выбрасывает.
Скилл находит такие места и чинит их.

## Что внутри

- **Аудит cite-safety** — каждый блок текста оценивается по шкале 0–10
  (извлекаемость, прямой ответ, фактологичность, структура, объём,
  имплицитные ссылки, нейтральность);
- **чек-лист самодостаточности** и каталог «слепых зон контекста»;
- **формула Trust Block**: [Утверждение] → [Объяснение] → [Граница
  применимости] → [Пример/Источник] — и 6 типов блоков под разные интенты
  (answer capsule, fact block, comparison, how-to, definition, key takeaway);
- **замены «размыто → конкретно»** («быстрое внедрение» → «внедрение за
  2–4 часа»);
- **безопасная JSON-LD-разметка** (Article, FAQPage, Organization) без
  нарушения structured data policies;
- **контракт с голосом канала**: что переводить в ETB, а что оставить
  живым — колонка и телеграм не превращаются в энциклопедию;
- **защита фактуры**: цифры, цитаты и атрибуции при переработке не
  меняются — только упаковка вокруг них.

Результат — таблица аудита (фрагмент → проблемы → переработанный блок →
как повышен cite-safety) и итоговый Cite-Safety Score до/после.

## Установка

### Claude (claude.ai)

1. Скачайте архив `zips/aeo-trust-blocks.zip`.
2. Загрузите на [claude.ai/customize/skills](https://claude.ai/customize/skills).
3. Скилл активируется сам по запросам вида «проверь текст для AI-выдачи»,
   «сделай AEO-аудит», «повысь цитируемость в AI-поисковиках».

### ChatGPT (Custom GPT или Project)

Готовый пак — в `gpt-packs/aeo-trust-blocks/`: содержимое `instructions.txt`
в поле Instructions, файл из `knowledge/` — в Knowledge. Пошаговая
инструкция — в README пака.

### Любой другой чат-бот (Gemini, Mistral, GigaChat, локальные модели)

Standalone-промт `prompts/aeo-trust-blocks.md`: скопируйте файл целиком
первым сообщением в чат, вторым сообщением пришлите текст на аудит.

## Как пользоваться

Пришлите готовый текст (статью, лендинг, документацию) и попросите AEO-аудит.
Скилл разберёт текст на блоки, покажет таблицу проблем, предложит
переработанные Trust Blocks и пересоберёт текст из принятых вами замен.

Скилл работает с **готовым** текстом. Он не пишет статью с нуля (для этого —
скилл `seo-article-writing`) и не заменяет фактчек: источники цифр он
требует, но достоверность не проверяет.

## Источники (source of truth)

Папка производная — собрана `make skills-export` из репозитория
content-agents, вручную не редактируется:

- `skills/optimization/aeo-trust-blocks/SKILL.md` — маршрутизатор
  (этот скилл);
- `skills/optimization/seo-trust-optimization.md` → `references/aeo-methodology.md` —
  полная методика (движковый скилл той же системы; в агентном конвейере
  подключается к 7 агентам на этапах доработки).

Методика обкатана в работающей контент-фабрике: скилл — этап production
pipeline, через который проходят SEO-статьи, лендинги, пресс-релизы и
статьи для СМИ перед публикацией.
