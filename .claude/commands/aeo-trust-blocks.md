Используй скилл `aeo-trust-blocks` (маршрутизатор `.claude/skills/aeo-trust-blocks/SKILL.md`,
полная методика — `references/aeo-methodology.md`: открывай её при работе, а не
пересказывай по памяти).

## Режим

- В аргументе есть «только аудит» / «оцени» / «audit» → **audit**: таблица блоков со
  score и проблемами, текст не трогаешь.
- Иначе → **rework**: таблица аудита, переработанные Trust Blocks для слабых мест
  (score < 8), затем пересборка текста из принятых пользователем замен.

Аргумент: $ARGUMENTS. Если текста нет — попроси вставить его следующим сообщением или
указать путь к файлу (читай инструментом Read). До начала одним вопросом уточни
целевой запрос: на какой вопрос читателя AI-поисковик должен отвечать этим текстом.
Один и тот же абзац cite-safe для одного запроса и бесполезен для другого.

## Процесс

1. Разбей текст на смысловые блоки по H2/H3 (без заголовков — по абзацам-тезисам).
2. Оцени каждый блок по шкале Cite-Safety Score 0–10 из справочника: извлекаемость,
   прямой ответ, фактологичность, структура, объём, имплицитные ссылки, нейтральность.
3. Покажи таблицу аудита: фрагмент → score → статус → проблемы.
4. В режиме rework переработай блоки со score < 8 по формуле
   **[Утверждение] → [Объяснение] → [Граница применимости] → [Пример/Источник]**,
   выбирая тип блока под интент (answer capsule, fact block, comparison, how-to,
   definition, key takeaway).
5. Спроси, какие замены принять (инструментом AskUserQuestion, если доступен).
6. Пересобери текст с принятыми блоками и покажи score до/после.

## Жёсткие правила

- Цифры, даты, цитаты, ссылки и атрибуции не меняются — только упаковка вокруг них.
  Сомнение в цифре — пометка `[NEEDS_FACTCHECK]`, не «освежение» по памяти.
- «По данным экспертов» и «исследования показывают» без источника и года запрещены;
  нет источника — блок переоформляется без цифры.
- Категоричность заменяй границей применимости: «X лучше» → «X оправдан, когда …».
- Голос не атомизируется весь: ETB-дисциплине подчиняются фактурные блоки; лид,
  переходы, авторская позиция и CTA остаются живыми (матрица по каналам — в
  справочнике). Колонку и телеграм-пост в энциклопедию не переписывай.
- Скилл аудирует готовый текст: с нуля не пишет и достоверность фактов не проверяет.

## Формат вывода

Строго по разделу «Формат вывода» скилла: таблица аудита (исходный фрагмент → статус →
проблемы → оптимизированный Trust Block → как повышен cite-safety) и сводка: блоков
проанализировано, готовых к цитированию, требующих переработки, общий score до/после.
Если все блоки уже ≥ 8 — так и скажи, без имитации переработки.
